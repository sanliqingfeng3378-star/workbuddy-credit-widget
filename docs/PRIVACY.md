# 隐私与本地数据

本应用是个人电脑上的官网查询工具，没有开发者运营的后端，也不会上传积分到项目维护者。

## 网络访问

内置 WKWebView 访问 `https://www.workbuddy.cn`，登录过程可能跳转到官网使用的身份验证服务。官网自身如何处理数据以官网政策为准。主应用在官网页面内通过同源请求查询 `/console/account`，然后查询个人积分 `/billing/meter/get-user-resource-summary` 或企业用量 `/v2/billing/meter/get-enterprise-user-usage`。应用程序不提取登录 Cookie、密码和令牌。

主应用在内存中暂时保存账号标识，用于区分账号；此标识不写入积分快照。桌面扩展仅访问本机 `127.0.0.1:38348`。服务拒绝带有 Origin 的请求和非预期 Host，不开放 CORS；它没有为本地进程提供身份验证，因此同一电脑上的程序可以读取积分和套餐信息。

## 存储

- 主应用积分快照：`~/Library/Application Support/WorkBuddyCreditWidget/snapshot.json`。
- 桌面扩展在自己的系统沙盒容器中保存快照，用于主应用暂时不可达时显示最近数据。
- WebKit 独立会话存储位于系统管理的应用数据目录，公开版应用标识是 `io.github.sanliqingfeng3378-star.workbuddycredits`。

主应用启动时不会直接显示之前的主应用缓存；它先验证当前官网会话。桌面扩展可能显示带更新时间的旧快照，直到下一次成功更新。登录失效后主应用会发布空快照，但扩展何时更新取决于系统调度。

## 停止使用

退出菜单栏应用后不再主动查询官网。若要移除，先通过官网登录窗口退出账号，移除桌面小组件，退出应用，再删除应用本体。需要清理残留快照时可以删除上述主应用缓存目录；系统沙盒及 WebKit 数据也可能残留，请按应用标识检查后清理，不要删除其他应用的数据。

## 反馈问题

请勿上传 Cookie、二维码、访问令牌、完整官网响应、系统容器目录或自己的积分快照。故障报告一般只需 macOS 版本、芯片类型、应用版本、界面错误提示和复现步骤。
